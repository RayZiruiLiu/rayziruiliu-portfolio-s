# Ray's portfolio - S version

The site opens "RayZiruiLiu_Portfolio.pdf" immediately in the browser using its native PDF viewer. There is no visible homepage, framework, or JavaScript.

To update the portfolio, replace "RayZiruiLiu_Portfolio.pdf" with the new PDF using the exact same filename, then commit and push to "main". The public link will stay the same.

For local preview, run "python -m http.server 8000" in this folder and visit "http://localhost:8000/".
